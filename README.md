# Missão: Sistema de Suporte à Vida

Bem-vindo ao repositório central da missão. Este documento descreve a estrutura dos nossos ambientes de trabalho e apresenta a equipe de engenharia responsável pela manutenção dos sistemas.

## Camadas do Ambiente

Para garantir a segurança, organização e estabilidade do código da nossa missão, utilizamos três camadas principais de ambiente:

- **develop (Desenvolvimento):** É o nosso ambiente de construção. Todas as novas funcionalidades, atualizações e correções de bugs feitas pela equipe são enviadas e testadas inicialmente nesta camada.
- **stage (Homologação/Staging):** É uma réplica do ambiente oficial. Utilizamos o stage para testes finais de qualidade e validação. É a última parada do código para garantir que tudo está perfeito antes de ir ao ar.
- **main (Produção):** O ambiente principal e oficial. Contém apenas o código 100% testado, estável e operacional que mantém a nossa missão rodando sem falhas.
